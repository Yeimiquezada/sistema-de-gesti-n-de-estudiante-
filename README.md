Descripción 

Sistema de Gestión de Estudiantes desarrollado en C# con Windows Forms. La aplicación permite registrar, consultar, buscar, actualizar y eliminar información de estudiantes. Utiliza listas dinámicas para almacenar los datos en memoria, validaciones, manejo de excepciones y enumeraciones para gestionar los datos académicos de forma organizada.

<img width="659" height="530" alt="image" src="https://github.com/user-attachments/assets/db33d40e-ff5d-45b0-88ae-757dee261ddf" />


 

 Datos de entrada

La aplicación permite ingresar los siguientes datos mediante los formularios: ID o matrícula, nombre completo, edad, sexo, carrera o programa de estudio y estado académico.

Datos que procesa

El sistema procesa la información de los estudiantes mediante validaciones de datos, manejo de excepciones, búsquedas, actualizaciones y eliminaciones utilizando una lista dinámica de estudiantes.



<img width="995" height="503" alt="image" src="https://github.com/user-attachments/assets/4826ff7b-36ac-4339-b729-f2a9e871f684" />


 Datos de salida

Los resultados se muestran mediante un DataGridView, mensajes de confirmación y mensajes de error utilizando MessageBox.
